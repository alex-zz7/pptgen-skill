# 心理课规范（只在场景族 = 心理健康 / 团体辅导 时生效）

其他场景（班级管理、家长会、仪式、安全、教师分享）不用本页；它们的讲稿叫主持稿 / 发言稿 / 流程单，收束到流程和实物件，可以讲纪律。见 [scenarios.md](scenarios.md)。

## 课型

心理健康课 / 团体辅导。不是主题班会，不是品德说教，不是语文课。

对应《中小学心理健康教育指导纲要》里**这一课真正用到的**条目。不要每份都把自我认识 / 情绪调适 / 人际 / 适应四条抄一遍。

## 课堂结构

暖身（降低评价威胁）→ 工作（动手）→ 结束（一小步）。

这是课型，不是页表，也不是理论栏目。章节名、页数、用什么理论，按这一次调研写。

## 3I 不是必用理论

**3I 不是本产品的必用理论。** 上一份用了，这一份不必再用。
没有单独的 3I 页，也不许在教案里再写一节 3I 来凑数。

禁止再写：

- 「设计理念」这一节，并用下面句式
- I am / I can / I have 三栏
- 「N页与3I的对应」
- 从上一份复制一级标题：课程定位、体验式活动逻辑、跟单而不跟、本课与主题班会的区别、教师常用技术、认知/情感/行为目标
- 为了凑字把同一段换名词再写一遍

禁止句式：

> 本课以X为情境素材，以Y为核心意象……通过系列体验式活动，将A与心理复原力相融合，引导学生运用3I理论……切实落实……

006 第二回翻车就是：PPT 页表改了，教案还是设计理念 + 3I + 页和 3I 对应。见 [failures.md](failures.md)。

## 教案要有的是功能，不是栏目名

老师打开这份文档，必须能看见：

1. **这一课要挡住的教室问题**（从调研来）
2. **这一课自己怎么带**（脊柱、物件、活动，用本课的词）
3. **逐页引导 + 提醒**（页数 >21 时，讲稿跟着加厚的停顿走）
4. **时间不够怎么砍**（正课厚，短课砍，不要反过来）
5. **安全**：自愿、保密、不诊断、不比较、转介。风险条目跟本课走——中秋写分离/不回家，教师节写扮演/被批评。下一份写这一课自己的风险。

一级标题每份重起。上一份用过的标题出现，停下来重写。

字数够讲稿和安全即可，大约 2800–4500 字。不要为了凑字灌理论。

## 和班会的界限

班会收束到纪律和口号。本课收束到**这一课自己的那一小步**。教师是带领者，不是道德裁判。
心理课不打分、不投影个人量表、不强迫发言。失败重写成“计划太大”，不重写成“你不行”。
