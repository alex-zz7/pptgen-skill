# 小红书文案

一条课件笔记里，**图轮播负责卖，正文负责让搜索找到，评论区负责成交**。三段分开写。

## 标题（≤20 字）

从场景取钩子，不从 SKU 名取。每个场景写 5 个候选，选 1 个：

| 钩子类型 | 例（2026-09 实搜高互动） |
|---|---|
| 反常识 | 班委竞选别只看人缘，这样投票更公平 |
| 后果 | 选了班干部不培训等于白选 |
| 实物 | 刚做的班干部聘书模板，A4 可编辑 |
| 老师身份 | 厉害的班主任开学第一课，不讲废话只立规矩 |
| 现场 | 开一场只说痛点不废话的家长会 |
| 数字 | 班干部培训这 26 页讲透了什么 |

不写：全网首发 / 必火 / 限时 / 仅 X 元 / 官方同款 / 备课热点｜A✖️B。

## 正文两种写法，按笔记目的选

**A. 搜索型（默认，跟高互动帖）**：2–4 行说这份怎么用 + 8–10 个话题标签。正文短，图多。

```
班里马上竞选班干部了，把报名、演讲、投票、唱票做成一套，投票前先讲三条约定。
聘书是 A4 可编辑的，班名姓名自己改。
完整课件在店铺。
#班干部竞选 #班委竞选 #班干部竞选ppt #主题班会课件 #班级管理 #班主任 #新学期班会 #小学班主任 #开学第一课 #班主任干货
```

**B. 讲述型（每个场景 1 条）**：老师说话，2–4 行现场 + 内容主线 + 📌 3–5 条具体做法 + 适用 + 标签。用来做「内容主线」搜索命中和收藏。

```
{口语标题}

{现场 / 吐槽，2–4 行}

这套不讲「要负责」，讲遇到事具体怎么办：
📌 同学不配合 → 先说规则再说人
📌 管错了 → 当天补救，不当众较劲
📌 哪些事马上找老师 → 三条边界写在卡上

{学段}，{实数}页，含逐页讲稿和 {实物件}。
完整课件在店铺。
```

两种写法都不写：私信 / 加微信 / 网盘 / 拉群 / 论文腔（设计理念、切实落实、3I）/ 诊疗词。页数字数用实数。

## 话题

4–6 个走发布页按钮（场景词 + 学段 + 班主任 + 节日/档期），正文末尾标签 ≤10 个。每条笔记标签不完全重复。

## 评论区（成交在这里）

- 置顶一条：「同款在店铺，点头像进；聘书可编辑」
- 「求分享 / 求课件」统一回：「在店铺里，点头像～」不回暗号、不发文件、不加微信
- 「有偿」回：「店铺里有，三个节点可以单买」
- 问「几年级能用」「能改字吗」「多少页」：按实数答
- 每天回一轮，回复也是内容

## 免费钩子（可选，一篇一个）

从实物件挑一个做成 PDF 挂「文件」组件（聘书 / 清单 / 表单）。文件里不写微信、不写网盘；平台会自动加作者水印。全套在店铺。带文件的笔记标题写明「附可下载」。
