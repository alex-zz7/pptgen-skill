# 调研（选场景之前）

没有调研表，不许写页表，不许定脊柱。调研不是给旧页表找借口，也不是只为心理课找题。

**调研要的是一张有实数的表，不是某一种浏览器。** ego lite 是首选，不是硬依赖。Windows 上现在装不了 ego lite（[官方只出了 macOS](https://github.com/citrolabs/ego-lite)），照样做课件。平台细节见 [platforms.md](platforms.md)。

## 用什么

打开方式和点法见 [xhs-browser.md](xhs-browser.md)。先看当前 agent 有什么（[hosts.md](hosts.md)）：有 `ego-browser` 用 ego；有可点击浏览器就点封面；只有 WebFetch 或什么都没有 → 把搜索词发给用户，用户自己搜完把数字贴回来。已经贴了藏/评/截图就直接填表。

小红书专搜的跟单流程在同伴 skill `xhs-banhui-scan`（和本仓库一起装）。不要 OpenClaw 浏览器，不要 Playwright，不要系统 Chrome 硬闯。

只记搜索卡和详情页上的实数。网页没有「已售」，写未取到，不要编。

## 看什么（按重要性）

1. **收藏和评论，不是赞。** 4 赞 / 665 评「求课件」的帖子比 500 赞的模板帖更能说明需求。记 `like / collect / comment / 「求」条数`。
2. **档期**：今天 ±14 天老师在忙什么（开学第一周 = 竞选、立规矩、家长会；考后 = 总结、家长会；节前 = 节日、安全）。
3. **场景族分布**：搜到的卡片打上 [scenarios.md](scenarios.md) 的族标签，看哪一族新帖密、赞低（供给多、需求真、没人做好），哪一族有实物件跑出来。
4. **实物件信号**：标题里有「模板 / 可编辑 / 可打印 / A4 / 表」的帖子单独记。
5. **头部卖家目录**：点 1–2 个卖家主页，抄下 SKU 目录（笔记标题列）和粉丝 / 获赞比。目录店的品类分布就是我们的品类分布参考。
6. **展示方式**：他们的图是套壳还是裸幻灯片、几张、封面写什么字。
7. **筛选条 / 相关搜索**：暴露的需求词（可打印、逐字稿、心理委员、课代表……）直接进商品标题。
8. **老师怕什么**：评论区的追问（几年级、能改字吗、多少页、有讲稿吗）。

## 跟不跟（写进 `design.md` 第一张表）

四列：别人在做什么 / 数据（藏·评·赞·日期）/ 跟不跟 / 逼出本单哪一块（哪一页、哪个实物件）。

跟：档期、真需求（评论）、实物件、流程完整度、买家追问。
不跟：学生端搞笑模板、99+ 免费打包、上一份自己的版式、已交付 SKU、单一 IP 且互动低。

## 停

- 调研只用来选题、页表仍从上一份抄，就是翻车。
- 已有 SKU 不重做。
