# 两段基础提示词

提示词 1 原文照做。提示词 2 是 Lucy 原版加一条密度要求（2026-09-06 评审：原版「充足留白、不堆砌」被执行成空页，见 [market.md](market.md)）。留白仍是排版原则，但每页必须先有内容。

## 提示词 1（风格）

分析参考图，提取整体画风与氛围，生成可直接用于 AI 绘图的风格提示词，用于中小学教育类 PPT 配图。
要求：只总结画风、色彩、光影、质感、氛围，不描述具体画面和人物内容；风格贴合中小学生心理，积极正向；直接输出提示词，不要多余内容。

## 提示词 2（页方案）

基于提供的逐字稿 / 教学设计与既定画面风格提示词，输出一套可直接施工的 PPT 制作方案，总页数按场景（正课 21 页以上，仪式 14–18，家长会 18–24）。补全缺失的内容。
整体要求：
1. 完整覆盖这一场活动从开始到结束的每一步，逻辑清晰，内容适配对应学段
2. 仅呈现课件正文内容，禁止加入课堂实录、学生反应、师生互动话术等非课件正文
3. 排版留白靠版式实现，不靠删内容：每一页正文必须有 ≥3 个信息单元，每个单元含标题和 2–3 行具体做法；信息多则拆页，信息少则并页
4. 全册插图统一沿用给定风格；全册共用一张背景，插图只用「4:3 小情境图 + 角色剪影」两类，不为每页另画整幅场景
单页需包含 6 项：1. 页职责（老师用这页干什么） 2. 页型（卡片 / 步骤 / 对照 / 清单 / 表格 / 互动 / 金句 / 章节） 3. 信息单元（逐条写全） 4. 横幅句（老师能直接念的一句收束） 5. 小情境图说明（若有） 6. 对应实物件（若有）
按页码逐条输出，结构清晰，无多余解释。
