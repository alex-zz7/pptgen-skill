# 内容矩阵：什么叫有商业价值

老师付钱买的不是画，是**替他想好了的具体做法 + 拿到手能用的东西**。判断一页有没有价值只问一句：老师能不能对着这页把这三分钟讲下来，学生能不能照着做。

## 内容来源（按优先级）

1. **场景流程本身**：这场活动从头到尾每一步。步骤就是页。
2. **岗位 / 角色 / 边界**：谁做什么、不能做什么、什么时候找老师。表格页、清单页。
3. **话术**：老师原话、学生可以直接说的句子（「我先上课，下节课再处理」）。对照页。
4. **情境**：班上真会发生的事 + 两三种处理。互动页。
5. **实物件字段**：报名表、评分表、聘书上有什么栏，页面上就讲什么栏。
6. **原件**（有的话）：认全、改写成能念的稿，事实数字保留。
7. 金句、寄语：最后放，≤2 页。

抒情、理念、理论名词（3I、认知情感行为）不是内容来源。

## 逐字稿 · 页方案 · PPT 的对应

三份文件仍分开写（见 [source-plan.md](source-plan.md)），但每页在三处必须对得上：

| 逐字稿 | 页方案 | PPT |
|---|---|---|
| 讲稿 3–6 句 + **插图**段 | 页职责、页型、≥3 信息单元、横幅句、底图代号 | `theme.js` 对应页型，单元逐条落卡/步/行 |

页方案里「要点式正文」必须写成信息单元（单元标题 + 2–3 行做法），不许写「介绍岗位职责」这种一句话概括。

## 实物件（每包 ≥2）

| 类型 | 例 | 格式 |
|---|---|---|
| 表单 | 报名表、投票单、计票表、诊断卡、值日表、家长联络卡 | A4 PDF + 可编辑 docx/pptx |
| 证书 | 聘书、进步卡、感谢卡 | A4 PDF + 可编辑（班名/姓名/日期是文本框） |
| 卡片 | 岗位职责卡 ×N、话术卡、任务卡 | A4 拼版 PNG/PDF，每卡 ≥4 行 |
| 公示 | 班规公示栏、班干部公约、周记录表 | A3/A4 PDF |

实物件用和课件同一套调色板、字体、母题。不写真实人名校名，留横线或「____」。文件名跟本场景（`聘书-班干部-可编辑.pptx`，不叫「附件1」）。

免费钩子：从实物件里挑 1 个最容易被存的（聘书 / 清单），做成 PDF 挂笔记「文件」组件；全套在店铺。

## 讲稿（教学设计 / 主持稿 / 发言稿）

按场景叫名：心理课叫教学设计，班会叫主持稿，家长会叫发言稿，仪式叫流程单。栏目每份重起，但功能要全：

1. 这一场要挡住的问题（从调研来）
2. 从进门到结束怎么走（时间 / 页码 / 老师说 / 学生或家长做）
3. 逐页引导词（每页 3–6 句，可以直接念）
4. 时间不够砍哪几页
5. 容易翻车的地方（冷场、公平争议、家长质疑、隐私）
6. 实物件怎么发、怎么收

约 2800–5000 字，按页数走。

## 商业价值自检

- [ ] 任抽 5 页，每页都能说出「老师用这页干什么」
- [ ] 每页 ≥3 单元、每单元有做法，不是形容词
- [ ] 有 ≥2 个可打印实物件，字段和课件页对应
- [ ] 可编辑处（班名、姓名、日期、岗位）都是文本框
- [ ] 讲稿能对着 PPT 念完整场
- [ ] 货架同类没给的那一样东西，我们给了（写进笔记第二行）
