## brief（六问）

| 问 | 答 |
|---|---|
| 老师哪一天打开 | 开学第 1–2 周（竞选）、第 2–3 周（培训）、第 3 周（聘任） |
| 从进门到结束几步 | 竞选 4 章 8 步：为什么选 → 岗位 → 报名 → 演讲 → 投票约定 → 投票 → 唱票 → 公布；培训 6 章；聘任 5 步 |
| 打印什么 | **只要两件**：聘书（钩子，可编辑 pptx + PDF）+ 投票单（当场表）。演讲提纲、职责、公约、话术、宣誓词都留在 PPT 页上，不再各做一份 PDF |
| 老师最怕 | 变成人气投票（公平争议）、选完不会干、仪式冷场 |
| 要改的字 | 班名、岗位名、候选人名、日期、班主任名 |
| 比货架多给 | 货架卖 3 个单独 PPT；我们给全流程 + 可编辑聘书 + 三份讲稿。笔记第二行就写这个 |

## 脊柱

一句话：**选上只是开始，上岗要有说明书，上任要有仪式。**
贯穿物件：一张聘书（竞选页出现空白聘书 → 培训页出现职责卡 → 聘任页填上名字）。
