# 图文 → 逐字稿 → 风格词 → 页方案

输入是 PPT、截图、照片或已有讲稿。用户已贴图就直接做。
三个产物分开写，不要合成一篇散文。落盘路径见 [SKILL.md](SKILL.md)。

## 1. 逐字稿

先把原件上的字和图认全，再改写成能对着讲的稿。

禁止原文整段粘贴。禁止收成摘要、丢掉案例和金句。事实、步骤、数字、引文保留，句子重写出口语。

有图就必须写清，单独成段，标 **插图**。写位置、主体、动作、照片还是手绘、关键物件、和字怎么让开。装饰也记一句；主图要写到能按这段重画。禁止只写「配图一张」。

手机截图：裁掉状态栏和「识图搜同款」，两页叠一张要拆开再认。看不清标「原图看不清」，缺页标「原件未提供」，不要编。

无原件时：按 `design.md` 页表写讲稿，每页仍要有 **插图**（给后面出图用）。

```
# 逐字稿 · {题目}

## 第N页 · {标题}

{改写后的讲稿}

**插图**
{位置、主体、媒介、物件、和文字的关系}
```

## 2. 风格提示词

只看参考图的画风。执行 [prompts.md](prompts.md) **提示词 1**，原文照做。
输出里只能有提示词，不要标题、不要解释。写入 `风格提示词.md`。

没有参考图：用本课 `style-bible` 写成同一形态的一段英文/中英提示词（画风、色彩、光影、质感、氛围），仍不写具体人物情节。

## 3. PPT 制作方案

用逐字稿 + 风格提示词。执行 [prompts.md](prompts.md) **提示词 2**。
缺章就补课程内容，不补互动稿。页数按场景（[page-types.md](page-types.md)）。信息多就拆页，信息少就并页。

每页写 6 项：页职责、页型、信息单元（≥3，逐条写全）、横幅句、小情境图说明、对应实物件。
方案里禁止课堂实录、学生反应、师生互动话术、具名案例故事。「介绍岗位职责」这种一句话概括不算单元。
