# 视觉宪法：一套课件一个世界

006/007 输在这里：每页一张不同的整幅画，字压在小纸条上。看起来像画册，不像老师能用的课件。见 [market.md](market.md) 第一节。

反过来做：**框架统一、插画是套件、字是主角、图退成舞台。**

## 1. 每套课件先写死 `workflow/style-bible.md`

- 一句话世界（一个教室、一张桌子、一块黑板……必须能听出和上一份不是同一个地方）
- 调色板 ≤6：paper / card / ink / title / accent / accent2（+ line / muted 派生）
- 字体 2 套，**只用可随包分发的开源字体**：正文 `Source Han Sans SC`，标题 `Source Han Sans SC Heavy`（海报感）或 `Source Han Serif CN Heavy`（典礼感）。otf 放进客户文件夹 `字体/`。不用苹方 / 兰亭黑 / 楷体等系统字体——买家在 Windows 上会被替换、行高变化导致错位
- 人物：年龄、校服、发型、肤色统一；一套课件只有一组孩子和一位老师
- 母题 2 个：本场景的物件（聘书、投票箱、黑板、小红旗……）+ 一个装饰纹样（纸胶带、贴纸、粉笔线）
- 禁：影视 IP、演员脸、图内汉字、水印、塑料 3D、通用股票插画、每页换画风

配色不复用上一份。金样国风五色（朱红 `C23A2B`、松青 `1F6B63`、奶油纸 `F4EBD8`、古金 `C9A227`、墨青 `1E2A2E`）只给国风题材；班级管理、家长会另配（例：暖橙 + 墨绿 + 米白 + 粉笔白；或 藏蓝 + 珊瑚 + 米灰）。

## 2. 框架（每页共用，由 `scripts/theme.js` 母版画）

| 件 | 位置 | 内容 |
|---|---|---|
| 标签旗 | 左上 | 场景/合集名（「班干部三件套 · 培训」）——填色旗，任何底图上都能读 |
| 标题 | 标签下 | 双色：主句墨色 + 关键词强调色（`【关键词】` 标记） |
| 引子 | 标题下（可选） | 一句话，说这页解决什么 |
| 内容区 | 中部 | 页型库之一，见 [page-types.md](page-types.md) |
| 收束横幅 | 底部 | 一句老师可以直接念的话（强调色填底、白字） |
| 页脚芯片 | 左下 | 课件名 |
| 页码章 | 右下 | `03 / 26` |

封面、章节页、结束页用同一调色板和字体，但不带标签旗和横幅。

## 3. 插画是套件，不是每页一张；一份课件一张背景

一套课件只生成这些图（全部同一风格锚点 `--ref`，图内无字）：

| 图 | 数量 | 规格 | 用途 |
|---|---|---|---|
| 封面主图 | 1 | 16:9 | 封面 / 结束页（降透明度）；留出标题区 |
| **全册背景** | **1** | 16:9，**中央 72% 留白**，装饰只在上下边缘和角落 | 所有正文页、章节页共用（`assets.bg`）。不要轮换多张——用户明确要「每页一个一样的背景」 |
| 小情境图 | 6–10 | **4:3，纯白底，只画人物动作** | 卡片顶部、大图页；提示词必须写「no notebook/paper/panels/tags/icons/frames, no text of any language」 |
| 教室实景 | 1（合集每节点 1） | 3:4，**正对、屏幕纯黑、近 16:9**，桌上摆本场景道具 | `mockup.py` 套壳出展示图 |

背景 prompt 必须写明「center 72% plain area for text, decoration only at edges」。出图后先逐张看：小图里出现任何文字、面板、标签，重出。

**风格从参考图来。** 用户给了参考图（哪怕是一张海报截图），先对它执行 [prompts.md](prompts.md) 提示词 1，合集按节点分别提取（例：晴空校园 / 说明书笔记本 / 红金典礼），写进 `风格提示词.md` 分节。没有参考图才自己写。

**图片一律按真实比例裁切。** `theme.js` 的 `fitImage()` 用 sharp 预裁到目标框比例；pptxgenjs 的 `sizing:cover` 不写裁切参数，不要依赖它。建完后抽查 `ppt/media` 里图片长宽比是否等于框的长宽比。

## 3.5 字要大，位置要用满

- **封面按海报排**（`skin.coverAlign:'center'`，默认）：标题横占画面 ≈88% 宽，按字数自动放到 96–112pt，配 10pt 白色柔光；上方一行「— — —  卖点短语  — — —」；下方一条实色副标色带（`skin.coverSubBand` / `coverSubText`），副标 ≤ 12 字一句话；再下两颗标签。封面图靠 `skin.coverZoom` / `coverShiftY` 放大并下移，让人物落在标题下方；顶部露出的底色用 `skin.coverBg` 补齐；`skin.coverTop` 控制整块起始高度，避开图里的装饰（如线圈、彩旗）。看用户给的参考图：标题不够大就是不合格
- 左对齐封面（`coverAlign:'left'`，块宽 8.6）只在图右侧有主体、左侧留白明确时用
- 正文字号默认 17pt、卡片标题 20pt、页标题 32pt、横幅 18pt；装不下的版式自动缩到最低 12pt，而不是一开始就小
- 有空位就放东西：便签、角色剪影、加大字号，不留大块空白让人觉得"没做完"

## 4. 字压图

- 标题、引子下面有近透明纸板（`theme.js` 默认开）
- 卡片、表格、横幅自带底色；不直接把散字放在图上
- 正文 ≥14pt（装不下最低缩到 12pt），卡片标题 ≥17pt，横幅 ≥15pt，页脚 12pt。行距显式 1.2，不用自动缩放
- 文字多到装不下：先缩字号、再缩图、再拆页；不许压到横幅。深底（红/蓝）上的文字列必须有卡片底板
- 强调色只用于关键词、编号、横幅；不给整段正文上色

## 5. 节奏

- 封面 → 目录/流程总览 → 章节页 → 3–6 页正文 → 互动页 → 章节页 …… → 收束页 → 结束页
- 相邻两页不用同一页型；同一页型全套不超过 40%，卡片页 ≤35%，版式 ≥6 种（cards / steps / compare / checklist / table / interaction / quote / feature / dialogue / timeline / bigNumbers）
- 全套只有一张背景（`assets.bg`），章节页用同一张背景 + 角色剪影区分，不轮换底图
- 有图的页图放一侧、字放一侧（feature）；没图的页用 `extras` 在空位放便签和角色剪影，不留大块空白

## 6. 展示图
