# 场景注册表

pptgen 不锁课型。每一单先在这里选一个**场景族**，再按该族的「买家 / 时机 / 流程 / 实物件 / 必备页 / 禁区」做。没有匹配的场景就按同一格式新增一条，不要硬套心理课。

场景决定：页表脊柱、实物件、笔记钩子、商品标题。视觉宪法和密度闸门对所有场景一样。

## 怎么选

1. 先看档期（今天 ±14 天老师在忙什么）和 [research.md](research.md) 的收藏/评论信号。
2. 一个 SKU 只做一个场景的一个节点；节点能串成流程的，做**合集**（例：竞选 → 培训 → 聘任）。
3. 写进 `workflow/brief.md`：场景族 / 节点 / 学段 / 时长 / 买家一句话 / 实物件清单。

## 场景族

### 1. 班级管理（班主任日常）

| 节点 | 买家在什么时候用 | 课堂/会议流程 | 实物件 | 必备页 |
|---|---|---|---|---|
| 班干部竞选大会 | 开学第 1–2 周 | 为什么选 → 岗位介绍 → 报名 → 演讲 → 投票规则 → 唱票 → 公布 → 寄语 | 报名表、候选人演讲卡、投票单、计票表 | 岗位一览表、投票三约定、演讲一分钟提纲、公平原则 |
| 班干部培训（说明书） | 竞选后 1 周 | 三重身份 → 各岗位每天做什么 → 能做/不能做/马上告诉老师 → 遇事三步 → 沟通话术 → 干部之间补位 → 公约 | 岗位职责卡 ×N、边界清单、班干部公约、周记录表 | 岗位职责表、边界三栏、情境选择、话术卡 |
| 班干部聘任仪式 | 培训后 | 宣读名单 → 颁聘书 → 宣誓 → 家长/老师寄语 → 合影 | **聘书（A4 可编辑）**、宣誓词、任命公告 | 名单页、聘书页、宣誓词页、寄语页 |
| 立规矩 / 班规共建 | 开学第 1 周 | 诊断卡 → 立规会 → 试行表决 → 公示 | 诊断卡、班规公示栏、周表决表 | 规则怎么写成能照着做的句子、奖惩、试行 |
| 课堂纪律 / 课间安全 / 卫生值日 | 随时 | 问题 → 规则 → 步骤 → 检查 | 值日表、检查表 | 情境对比页（这样做/而不是） |

### 2. 开学 · 期末

| 节点 | 时机 | 实物件 | 必备页 |
|---|---|---|---|
| 开学第一课（立规矩版 / 收心版 / 学科版） | 开学前 3 天—第 1 周 | 新学期目标卡、班级公约 | 底线三条、第一周作息、怎么求助 |
| 期中/期末总结班会 | 考后 | 自评表、进步卡 | 数据怎么看、下一步一件事 |
| 寒暑假安全 · 假期计划 | 放假前 1 周 | 安全清单、假期计划表 | 十条清单、家长配合三件事 |

### 3. 家长会

| 节点 | 时机 | 实物件 | 必备页 |
|---|---|---|---|
| 新一年级 / 新初一 开学家长会 | 开学第 1–2 周 | 家长配合清单、联络卡、作息表 | 班级情况、老师怎么带、家长做什么、怎么联系 |
| 期中 / 期末家长会 | 考后 | 成绩怎么看（不排名）、家庭学习约定 | 只说痛点不废话、下一阶段三件事 |
| 幼儿园（小/中/大班） | 学期初 | 入园准备清单 | 一天流程、家长常问 |

### 4. 心理健康 / 团体辅导

课型规范见 [psychology.md](psychology.md)（只在本族生效）。节点：情绪、人际、挫折、生命教育、考试焦虑、节日缺口（中秋不回家的孩子）。实物件：活动单、卡片。收束到「一小步」，不收束到纪律。

### 5. 安全教育

课间 / 交通 / 防溺水 / 防欺凌 / 网络 / 消防 / 食品。实物件：安全承诺书、家庭检查表。必备页：真实情境 → 判断 → 正确动作 → 求助电话。

### 6. 节日 · 纪念日

教师节、中秋、国庆、重阳、元旦、清明、五四、六一、毕业。必备：把节日落到「班上能做的一件事」，不做文化科普堆砌。实物件：卡片、任务单。

### 7. 品德 · 励志 · 学习方法

诚信、感恩、时间管理、内驱力、读书方法、注意力、习惯养成。必备页：情境对比、可执行清单、一周打卡表。实物件：打卡表、清单卡。

### 8. 教师成长 · 分享 · 汇报

经验分享、说课、班主任基本功比赛、述职。买家是老师自己。必备页：问题 → 做法 → 证据 → 反思。实物件：讲稿、时间轴。视觉更沉稳，页数 18–25。

## 每个场景都要回答的六问（写进 brief.md）

1. 老师在哪一天打开这份文件？那天他缺什么？
2. 这节课/这场会从进门到结束，一共几步？每一步老师要说什么、学生/家长要做什么？
3. 哪些东西要打印出来发到手上？字段是什么？
4. 老师最怕出什么问题（冷场、公平争议、家长质疑、时间不够）？哪一页替他挡？
5. 页面上有哪些是要老师改的（班名、姓名、日期、岗位）？做成可编辑的文本框，不烤进图里。
6. 货架上同类在讲什么、缺什么？我们多给的是哪一个实物件或哪一步流程？

## 合集规则

- 合集 = 同一场景族里能串成流程的 2–3 个节点，共用一套视觉世界（同一风格锚点、同一框架、不同标签色）。
- 每个节点单独成 PPT 文件，实物件单独成 PDF/PNG，但放进同一个客户文件夹。
- 商品标题写全流程：例 `班干部三件套 竞选大会+培训说明书+聘任仪式 课件讲稿聘书`。
- 笔记可以一次发合集，也可以三条笔记各发一个节点再互相引。
