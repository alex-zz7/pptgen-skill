# 页型库与密度闸门

每一页先写「页职责」（这页替老师做什么），再从页型库挑一个能装下 ≥3 个信息单元的版式。写不出 3 个具体单元，说明这一页不该单独成页，并进上一页或删掉。

`scripts/theme.js` 已实现全部页型；`scripts/qa-density.py` 卡下面的数字。

## 密度闸门（正文页）

| 项 | 最低 | 说明 |
|---|---|---|
| 信息单元 | ≥3 | 一张卡、一个步骤、一行表格、一条清单、一句横幅各算 1 |
| 可见字数 | ≥60 | 不含标签、页脚、页码 |
| 具体做法 | 每单元 3–4 行完整句 | 写「怎么做」+ 一个「例：」，不写形容词，不写 6 字短语 |
| 收束横幅 | 1 句 | 老师能直接念的话 |
| 正文字号 | ≥14pt | 卡片标题 ≥17pt |
| 字体 | ≤2 种 | 微软雅黑（典礼可用宋体），不随包附字体文件 |
| 溢出 | 0 | `qa-density.py` 估算文本高度超框 3% 或压到横幅即 FAIL |

封面 / 章节页 / 结束页免密度，但必须在同一世界里。

不合格模式（见了就重写）：标题 + 三个短句；一张大图 + 一句金句；四个大字 + 副标题；只有编号没有做法。

## 页型

### 卡片 `cards(slide, items, {cols, bannerAfter, fill})`

2–4 张，每张：编号 + 标题 + 2–3 行做法 (+ 顶部小情境图 + 脚注)。
用于：岗位 / 身份 / 问题 / 原则。三卡最稳。
例：你为什么坐在这里 → 同学不听你的 / 有人当面怼你 / 自己成绩掉了。

### 步骤 `steps(slide, items)`

横向 3–5 步，箭头相连，每步 2–3 行。
用于：流程（报名 → 演讲 → 投票 → 唱票）、三步法、一周安排。

### 对照 `compare(slide, left, right)`

左「这样做」右「而不是」，各 3–4 条。
用于：指令、话术、纪律处理、家长沟通。老师最爱存这种页。

### 清单 `checklist(slide, items, {cols})`

带方框的 5–10 条。
用于：能做 / 不能做 / 马上告诉老师；安全十条；家长配合清单。可直接对应实物件。

### 表格 `table(slide, header, rows, {colW})`

原生表格 3–5 列 × 4–8 行。
用于：岗位职责表、评分表、时间表、值日表。表头用 accent2 填色。

### 互动 `interaction(slide, question, options, hint)`

情境 + A/B/C 选项 + 点击后出现的提示。
用于：情境选择、投票前热身、家长会现场提问。每 5–6 页放一次。

### 金句 `quote(slide, text, by)`

大字引言 + 出处。全套 ≤2 次，且仍要横幅收束。不许连续两页金句。

### 大图 + 要点 `feature(slide, img, items, {side})`

一张 4:3 大图（左或右）+ 2–4 个编号要点，每点 2–3 行。
用于：一个场景讲透一件事（管纪律 / 收作业 / 聘书上写什么）。

### 对话 `dialogue(slide, items)`

2–4 个气泡，`good:false` 的是「而不是」版本，带头像圆。
用于：话术、演讲示范、监督怎么说。比对照表更像真实场景。

### 时间线 `timeline(slide, items)`

3–5 个节点在一条横轨上，每节点 时间 + 标题 + 2–4 行。
用于：第一周三件事、第一个月检查点、仪式后一周。

### 大数字 `bigNumbers(slide, items)`

2–4 列大数字 + 标题 + 2–3 行。
用于：一分钟 / 三句话 / 一件事；三重身份；老师看重的三件事。

### 便签 `note(slide, text)`

页面右下的黄色便签，写「老师提示：…」或「例：…」。每 3–4 页放一次，既是内容也是设计。

### 版式分布

每份课件 ≥6 种版式；卡片页 ≤35%；相邻两页不同版式。全是三卡片就是用户说的「模板味」。

### 空位 `extras(slide, {note, mascot})`

每个正文版式排完都会在 `slide.__bottom` 记下内容底边；`extras` 看剩余高度：≥1.0 英寸放便签（老师提示）+ 右侧角色剪影，≥0.9 只放角色，再小就在右上角放小角色。没图的页一律调它，不留空白。

### 章节 `section({n, title, sub, mascot})`

序号（88pt）+ 章题 + 一句承诺（这一章结束后老师/学生能做到什么），右侧一个抠底角色。背景同正文页，不换图。

### 封面 `cover({title, sub, tagline, chipLeft, chipRight})` / 结束 `closing({title, words, thanks})`

封面是海报：标题 `【】` 标关键词，自动放到 96–112pt 横占 ≈88%；`tagline` 是上方一行卖点（`— — —  小岗位 · 大担当  — — —`，撞装饰就传 `null`）；`sub` 一句 ≤12 字进副标色带；chip：学段 + 场景族（「小学 · 班级管理」）+ 页数/含讲稿。皮肤项见 [visual.md](visual.md) §3.5。结束页收四个词，每词一句，标题 30–48pt 自适应。

| # | 页职责（老师用这页干什么） | 页型 | 信息单元（≥3，写全） | 横幅 | 底图 | 实物件对应 |
|---|---|---|---|---|---|---|
| 05 | 让学生分清三重身份的优先级 | cards×3 | 学生：…／管理者：…／老师搭档：… | 三个身份有轻重：学生 > 管理者 > 搭档 | A | 岗位职责卡 |

每格都要填。空格子就是空页。

## 页数

正课默认 >21 页；仪式类（聘任）14–18；家长会 18–24；教师分享 18–25。加厚的是流程停顿和实物件对应页，不是重复卡片。
