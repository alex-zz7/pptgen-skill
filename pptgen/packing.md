# 打包

外面压缩包里要包含：**客户文件夹、客户压缩包、小红书运营资料文件夹**。就这三样。

- 只打 **一个** `{短名}-输出全套.zip`
- 放到项目文件夹**外面**（`{项目父目录}/{短名}-输出全套.zip`）
- 客户压缩包只压客户文件夹里的文件，根目录平铺，不要再套一层同名文件夹
- 客户压缩包不压运营资料
- 小红书运营资料以**文件夹**放进全套，不要再压成 zip；文件夹内部平铺，不要子目录
- 不要：桌面、项目里的零散 zip、再套一层外壳、txt、mp4

```
{PPT名}/
{PPT名}.zip
小红书运营资料/
```

跑 skill 里的脚本，不要手改结构：

```bash
python3 {baseDir}/scripts/pack.py \
  --proj {项目绝对路径} \
  --ppt-name {客户文件夹名} \
  --short-name {短名}
```

改了任何交付文件（哪怕只是封面）都要重新 `pack.py`，并把新 zip 路径报出来；展示图 / 运营图 / 文案先重出再打包。

打完在对话里报 zip 的绝对路径和完整文件清单。**不发微信**（2026-09-06 起用户要求，以后也不需要）。

运营资料里唯一允许的子文件夹是 `展示图/`（保留一层），其余平铺。
