# 每份必须重做结构

框架（`theme.js` 母版）和页型库可以复用——那是产品的统一性。
**脊柱、页表、单元内容、章节名、实物件、讲稿栏目**不可以复用——那是每一单的价值。

翻车记录见 [failures.md](failures.md)。

## 钉死

每一份的 **文案、流程骨架、页表、信息单元、实物件字段、讲稿栏目** 都按 **这一次的场景和调研** 重做。

禁止：

- 上一份 `design.md` 页表改几个名词接着用
- 上一份 `build-ppt.js` 换色换图换标题（用 `theme.js` 新写，每页从页方案落）
- 固定套：路线站牌、左手账、3I 屏风、一问三折、ABCD 四选、四个大字搁板、五条选票、居中练习单、齐读胶囊
- 每份都写「设计理念：本课以X为情境素材……」
- 文案槽位搜索替换
- 讲稿一级标题从上一份复制
- 上一份的插画当这一份的站牌 / 连环

章节用**这一场景的物件或问题**命名（「投票前三条约定」「能做 / 不能做 / 马上告诉老师」）。

## 做之前

`design.md` 必须先有：

1. **调研跟不跟**（[research.md](research.md)）：别人在做什么、藏评数据、跟不跟、逼出本单哪一页 / 哪个实物件
2. **场景六问**（[scenarios.md](scenarios.md)）
3. **脊柱**：一句话 + 贯穿物件。抽掉字，老师能说出「这是哪一场」
4. **页表**（[page-types.md](page-types.md) 格式）：每页 页职责 / 页型 / ≥3 单元 / 横幅 / 底图 / 实物件对应

页表里出现上一份的章节名或单元句，停下来重写。

## 页数

正课 >21；仪式 14–18；家长会 18–24；教师分享 18–25。
加厚 = 流程里每个停顿都有页。不是每页再配一张打印件。

## 做完自检

任抽 5 页：

- 框架一致（这是对的），但内容不能是上一份换词
- 每页 ≥3 单元、有横幅、有页职责
- 实物件字段和文件名跟本场景
- 讲稿抽掉场景名词，不能还是上一份的骨架
- `qa-density.py` PASS
