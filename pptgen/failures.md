## 00. 班干部三件套 v1 被打回（2026-09-06）

用户原话要点：一股 AI 味、模板味；主题乱七八糟，每页一个一样的背景就够；组件和图片明显被拉伸；每页图文没精心设计；风格没从输入提取；内容太水，没人会买。

核实后全部成立，根因：

| 问题 | 根因 | 现在的规则 |
|---|---|---|
| 图片被拉伸 | pptxgenjs `sizing:{type:'cover'}` **不写 srcRect**，1:1 小图被拉成 2.4:1；mockup 留黑边阈值放到 20%，实景屏幕 1.6 直接铺满 | 所有图片走 `theme.js fitImage()` 预裁；`mockup.py` 任何情况保持页面比例 |
| 主题乱 | 三张舞台底图轮换 + 每张卡片透出不同小图 | **一份课件一张背景**（`assets.bg`），装饰只在边缘 |
| 风格没提取 | 用户给了参考图，我自己写了米色水彩 | 有参考图必须先执行提示词 1，逐个节点提取；风格词写进 `风格提示词.md` 分节 |
| 模板味 | 60% 页面是三卡片 | 版式库 11 种，每份 ≥6 种；卡片 ≤35% |
| 内容水 | 单元只写 6–10 字短语 | 每单元 3–4 行完整句，带「例：」；便签写老师提示 |
| 小图跑偏 | 「说明书」风格词让模型把小图画成带英文的手册页 | 小图提示词固定：只画人物动作、白底、无任何布局、无字；出图后必须逐张看 |

**以后：** 出图后先看图再排版；建完先查 `ppt/media` 尺寸比例；展示图先出一张核对比例；风格从参考图来，不自创。

## 000. 字体替换让买家看到错位（2026-09-06，同一单第四轮）

用户在 PowerPoint 里看到竞选第 11 页第二、三段错位；Keynote 里看着正常。根因：macOS 字体（兰亭黑 / 苹方）在 Windows 被换成微软雅黑，行高变大；加上大图版式右栏总高超过横幅、要点末尾多一个空段落、项目符号默认缩进 0.375 英寸导致换行。

**以后的规则：**

- **只用可随包分发的开源字体**：正文 `Source Han Sans SC`、标题 `Source Han Sans SC Heavy`（Heavy 族不加粗）、典礼类标题 `Source Han Serif CN Heavy`。字体 otf 放进客户文件夹 `字体/`，注意事项写"先安装字体"。
- **行距显式化**：正文文本框写死 `lineSpacingMultiple: 1.2` + `paraSpaceAfter: 4`，不依赖平台默认，不用 `fit: 'shrink'`（Keynote 不执行，PowerPoint 只在编辑时执行）。
- **末段不换行**：富文本最后一个 run 的 `breakLine` 必须为 false，否则多一个空段落。
- **项目符号缩进写死 14pt**，估算换行时按它算。
- **高度按内容算**：装不下先缩字号（≥12pt）、再缩图（≥0.75 英寸），仍不够就拆页，不许让文字压到横幅。
- **深底必须有底板**：大图版式右栏、金句页都带卡片底板。
- **QA 两道新闸**：`qa-density.py` 估算文本框需高超过框 3% 即 FAIL；任何内容跨过横幅顶线即 FAIL。

## 0000. 封面字太小、页面没用满（2026-09-06，同一单第五轮）

用户原话：封面的字没有像参考图那样做成超大字体；有位置就多利用，用的人看着舒服。v3 封面标题只有 46pt 缩在左侧。

## 0. 007 用爱耕耘：pptgen 版输给扣子（2026-09-04）

用户原话大意：pptgen 做的 23 页比扣子差；没有一个主题背景应用到每一张，整体不统一；内容排版空洞、模版化，没有商业价值，别人不会买。

做错的事：

**以后：**

- 一套课件一个世界：母版框架（标签旗 / 双色标题 / 横幅 / 页脚 / 页码）每页共用，插画做成套件（封面 + 2–3 舞台 + 小情境图），见 [visual.md](visual.md)
- 每正文页 ≥3 信息单元、≥60 字、一句横幅；`qa-density.py` 不过不打包，见 [page-types.md](page-types.md)
- 场景从 [scenarios.md](scenarios.md) 选；心理课只是一族
- 交付里必须有可打印实物件和 16–18 张一体机展示图，见 [showcase.md](showcase.md)
- 扣子稿的问题（烤字进图、模糊残图、水印）不是我们的路：文字必须可编辑，图内无字

## 0000000. 实物件做成资料包

**现象**：班干部三件套 `实物件/` 里塞了报名表、演讲卡、投票单、计票表、职责卡×9、公约、记录本、话术卡、宣誓词、任命公告、聘书，每张还 PDF+PNG。用户：东西太多、没必要那么复杂。

**根因**：把「货架上有实物件信号」理解成「流程里每一步都印一张」。聘书才是钩子；职责和话术已经在 PPT 上。

**规则**：正好 1 个钩子 + 最多 1 个当场表，≤3 个文件。PPT 里有的表不要再做打印件。见 [content.md](content.md)。

## 000000. 把 ego-lite 当成 Win 也能装的硬依赖

**现象**：skill 写「浏览器只走 ego lite」。ego-lite 官方只出 macOS（https://github.com/citrolabs/ego-lite），Windows 用户会卡在调研。

**规则**：ego 是调研首选，不是做课件的前提。没有 ego 就用用户贴的藏/评，或 Cursor 内置浏览器。不要把 ego-lite 打进本仓库，也不要在 Win 上装它。见 [platforms.md](platforms.md)。

## 00000. 任务结束后还在弹 Keynote / 终端窗口

**现象**：用户说"为啥结束了你还偶尔莫名其妙的打开预览"。每次重建后我都用 Keynote 导出 JPEG 目检，AppleScript 里带 `activate`，Keynote 就跳到前台；出图用 `tell application "Terminal" to do script` 开了终端窗口。

**规则**：视觉 QA 只用 `scripts/keynote-export.sh`（不 activate、进程隐藏），导完 `quit`；长任务用 tool 的后台模式，不开终端窗口；用户的桌面上不该出现任何我打开的窗口。
